# Document Analysis Tool

## Introduction

The Document Analysis Tool is an application designed to help you analyze text content within PDF documents. It allows you to search for specific words or phrases across multiple documents, find contextual relationships, and visualize the results in various ways.

## Key Features

- Upload and process multiple PDF documents
- Search for keywords across all documents
- Advanced search options including fuzzy matching and context awareness
- View results in various formats (tables, word trees, charts)
- Export analysis results to Excel or PDF

## Getting Started

### Installation

1. Download the application package for your operating system
2. Extract the files to a location on your computer
3. Open the application by double-clicking the main executable file

### System Requirements

- Modern web browser (Chrome, Firefox, Edge, or Safari)
- Minimum 4GB RAM (8GB or more recommended for large documents)
- Sufficient disk space for your documents

## How to Use

### Step 1: Upload Documents

1. When you first open the application, you'll see a document upload area
2. Drag and drop PDF files onto this area, or click "browse" to select files
3. The application will process your documents and extract text content
4. For large files, this may take some time - a progress bar will show status



**Tips:**
- You can upload up to 20GB of documents, but individual files should be under 200MB
- If processing is taking too long, you can click "Pause" and resume later

### Step 2: Configure Keyword Analysis

1. After uploading documents, scroll down to the "Keyword Analysis" section
2. Enter one or more keywords you want to search for
3. Optionally, add a category name for each keyword to help organize results
4. Click "Advanced Options" to access more detailed search settings:
   - Case sensitivity: Match exact uppercase/lowercase letters
   - Exact text matching: Find text within words
   - Fuzzy matching: Find words that are similar but not exact matches
   - Context requirements: Specify words that should appear before or after your keywords



**Tips for Advanced Search:**
- **Context Requirements** are powerful for finding specific phrases or situations
- Use "Words Before" to specify text that must appear before your keyword
- Use "Words After" to specify text that must appear after your keyword
- The "Context Range" determines how many words to look at before and after
- Choose "Match ANY context (OR)" if any one condition is enough
- Choose "Match ALL context (AND)" if all conditions must be met

### Step 3: Run Analysis and View Results

1. After configuring your keywords, click "Analyze Documents"
2. The application will search all documents for your keywords
3. Results will be displayed in the "Analysis Results" section
4. Click on a document name to expand and see details
5. Click "Show Matches" to see the exact text surrounding each match



### Step 4: Explore Advanced Visualizations

After analysis, you can use several ways to explore your data:

- **Show Raw Text**: See the full document text with keywords highlighted
- **View Word Trees**: See visual patterns of how words appear in context
- **Export Charts**: Generate and download visual charts of keyword frequency
- **Export to Excel**: Save detailed results in spreadsheet format

## Common Issues and Solutions

### Documents Not Processing

If your documents fail to upload or process:
- Check that they are valid PDF files
- Ensure they are not password-protected
- Try reducing the file size (under 200MB per file)
- Process fewer files at once if your computer has limited memory

### Search Not Finding Expected Results

If your search isn't finding expected keywords:
- Check spelling and try different forms of the word
- Disable case sensitivity if you're unsure about capitalization
- Try fuzzy matching with a high similarity threshold (0.8-0.9)
- For phrases, use exact text matching option

### Application Running Slowly

- Close other memory-intensive applications
- Process fewer documents at once
- Use the pause feature during document processing
- For large documents, the application may truncate very long text content

## Advanced Features

### Word Trees

Word trees help visualize the context around keywords:

1. Click "View Word Trees" from the results section
2. Select a keyword from the dropdown menu
3. Explore how the keyword appears in different contexts
4. Adjust the "Words to Show" setting to see more or less context
5. Use zoom controls to adjust the view

### Chart Exporter

Generate visual charts showing keyword frequency across documents:

1. Click "Export Charts" from the results section
2. Review the preview charts
3. Click "Download Charts" to save as PDF

### Memory Monitor

In the bottom-right corner, a small display shows memory usage. This helps you track how much of your computer's resources the application is using while processing large documents.
